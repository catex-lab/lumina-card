# 工序 1 — 识别原图 (Analyzer)

**目标**：在不修改图像的前提下，产出一份结构化「诊断报告」，为后续所有决策提供依据。

**输入**：用户上传的原始图片。

**输出**：一份结构化报告，包含以下字段：

| 字段 | 说明 |
| --- | --- |
| `scene_type` | 风景 / 人像 / 建筑 / 街拍 / 宠物 / 美食 / 夜景 / 其他 |
| `subject` | 主体是什么（人 / 物 / 建筑 / 自然元素），在画面中的位置与占比 |
| `lighting` | 自然光 / 室内光 / 逆光 / 夜景 / 混合，整体明暗 |
| `mood` | 宁静 / 活力 / 怀旧 / 都市 / 治愈 等情绪标签 |
| `defects` | 问题清单：模糊、噪点、过曝/欠曝、杂物、倾斜、水印、低分辨率 |
| `suggested_template` | 根据场景推荐模板（classic / minimal / vintage / editorial） |
| `notes` | 其他观察（构图、色彩倾向、特殊亮点） |

**步骤**：

1. 用 Read 工具查看图片，仔细观察每一个细节。
2. 逐项、如实填写报告字段；**看不到的信息不臆测**，标注「未知」而非编造。
3. 若图片分辨率过低（短边 < 800px），在 `defects` 标记 `low_resolution`，并提示后续 retouch 必做放大。
4. 把报告回传给用户，并进入 `subject-lock.md`。

**注意**：此阶段**只分析、不改图**。不要调用 ImageGen。
