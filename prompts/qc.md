# 工序 6 — 最终验收 (QC)

**目标**：对成品逐项核对，全部通过才可交付；不达标打回对应工序。

**输入**：post 成品 + 各工序报告（analyzer / subject-lock / compretouch / art-transform / color）。

**检查清单（逐条核对）**：

- [ ] 分辨率达标：屏幕分享用 ≥ 1024px 短边即可；实体印刷用须 ≥ 1600px 短边，确认已在 `post` 前对重绘底图做 2× 超分
- [ ] 主体清晰、无损伤、无畸变
- [ ] 干扰物已去除、无水印残留
- [ ] 色调统一、符合所选模板情绪
- [ ] 排版正确：文字可读、无溢出 / 重叠、位置符合模板
- [ ] 边框 / 装饰符合模板
- [ ] 整体美观、主体突出、一眼看懂「讲什么」

**打回规则**：

| 问题类型 | 打回到 |
| --- | --- |
| 清晰度不足 / 畸变 / 比例裁切 | `compretouch.md` |
| 印刷分辨率不达标（短边 < 1600px） | 对 `art-transform` 底图做 2× 超分后重跑 `post.md` |
| 画风不符 / 主体变形（艺术化问题） | `art-transform.md` |
| 色调 / 脏色 / 情绪不符 | `color.md` |
| 排版 / 文字 / 边框 | `post.md` |
| 主体丢失 / 焦点错误 | `subject-lock.md` |

**交付**：全部打勾后，用 `present_files` 交付成品，并附一句话说明——用了哪套模板、哪种艺术媒介、主题是什么（如「classic 模板 · 水彩 · 京都秋日」）。

若任一项不达标，明确指出哪一项、为什么，并打回对应工序重做，不带着问题交付。
